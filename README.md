# Desarrollo de software embebido a partir de contenedores
## Caso Docker

Mini-taller desarrollado para el curso **Taller de Sistemas Embebidos** del
Instituto Tecnológico de Costa Rica.

## Objetivo

Analizar el uso de contenedores Docker en el desarrollo de software para
sistemas embebidos, incluyendo:

- Entornos de desarrollo reproducibles y controlados.
- Diferencias entre contenedores y máquinas virtuales.
- Uso de Docker en el Development Host.
- Contenedores ejecutándose directamente en Embedded Linux.
- Diferencias entre arquitecturas AMD64 y ARM64.
- Imágenes Docker multi-platform.
- QEMU, nodos nativos y cross-compilation.
- Docker BuildKit y multi-stage builds.
- Beneficios y overhead de la contenerización en sistemas embebidos.
